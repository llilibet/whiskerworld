# TP5 — Refatoração

Refatoração é a modificação da estrutura interna do software **sem alterar seu comportamento observável**. Nesta etapa, aplicamos quatro refatorações do catálogo de Martin Fowler ao Whiskerworld, tomando como referência o [capítulo 9 de *Engenharia de Software Moderna*](https://engsoftmoderna.info/cap9.html).

Cada refatoração tem sua própria pasta, com justificativa, código antes/depois, *code smells*, exemplos planejados e oportunistas e par neutro A/B.
